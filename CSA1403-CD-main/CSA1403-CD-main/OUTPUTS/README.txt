COMPILER DESIGN LAB - SAMPLE OUTPUTS (EXPERIMENTS 1-18)
=======================================================

This folder contains one sample output transcript for each of the 18 C programs
in the supplied Compiler_Design_Lab_C ZIP archive.

Files:
  EXP01_Output.txt through EXP18_Output.txt

Each transcript includes the sample input (where required) and the program output.
The input values are examples; your faculty may require different test cases.

Important:
- These are sample outputs generated by compiling and running the supplied main.c
  programs with GCC.
- Experiment 5 reads until EOF. The sample run used two lines of text.
- Experiment 11 demonstrates insert, search, display, delete, display, and exit.
- Experiment 15 uses the sample.txt file included with the supplied project.
- Experiments 7-10 and 17-18 display fixed grammar/set results without input.

To use:
1. Extract this OUTPUTS folder.
2. Copy it into the root of your Compiler_Design_Lab_C repository.
3. Run: git add OUTPUTS
4. Run: git commit -m "Add sample outputs for experiments 1-18"
5. Run: git push

Check the outputs against your own run before submitting them as lab-record evidence.
